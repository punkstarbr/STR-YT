# Logos raster

Estes PNGs substituem referências SVG nas playlists para compatibilidade com players IPTV que não exibem SVG. Os arquivos mantêm a proporção e o conteúdo visual das fontes; foram conferidos visualmente em 2026-11-02. As playlists usam os arquivos públicos em `https://raw.githubusercontent.com/punkstarbr/STR-YT/main/logos/`.

|---|---|---|

| `canal_rural.png` | Canal Rural | [CDN oficial, SVG](https://imagens-cdn.canalrural.com.br/2023/08/MkE8B6GU-cr-logo-header.svg) |

Os PNGs derivados de arquivos do Wikimedia foram rasterizados para uso no player; os originais vetoriais não são referenciados pelas playlists. O logo WebP da TV Canaria foi convertido para PNG. As marcas permanecem propriedade de seus titulares.
